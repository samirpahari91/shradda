How to read these numbers

  • Scores are grouped-CV, not optimistic K-fold. Roughly 15–35 % of dataset rows share an identical process-input vector with another row (one study reporting several measurements for a single setting). Ordinary K-fold splits those twins across train and test, which inflates scores — for grain size by more than 0.4 R². Every number here keeps replicates together.
  • The ceiling is the data, not the model. 51–100 % of each property's variance is between-study — driven by alloy, machine, powder and heat treatment, none of which are columns in this dataset. Adding a fancier algorithm does not help; adding an alloy label would.
  • Use for screening, not qualification. Predictions are alloy-agnostic averages over many materials and machines. Expect a real offset for any single machine until you recalibrate.
  • Extrapolation is flagged. Inputs outside the training range get a warning — tree ensembles cannot extrapolate and will silently clamp to their edge prediction.
